🎯 Project Overview

Migrating Fastbreak Analytics from Next.js (T3 stack) to TanStack Start while preserving all existing functionality. The app includes team management, player tracking, game statistics, and basketball court shot visualization.

📦 Current Stack

Framework: Next.js 15 with App Router
API Layer: tRPC v11 with three routers
Database: Drizzle ORM + Turso (SQLite edge)
Auth: Clerk v6 with middleware protection
State: TanStack Query for client state
Styling: Tailwind CSS + Radix UI

🛣️ Route Structure

/ (home page)
/team (teams list)
/team/new (create team)
/team/[id]/player (players list)
/team/[id]/player/new (add player)
/team/[id]/game (games list)
/team/[id]/game/new (create game)
/team/[id]/game/[gameId] (game details)
/team/[id]/game/[gameId]/stats (shot tracking)

🏗️ Migration Architecture

Architecture Transformation

✨ Migration Benefits

Immediate Improvements

  • • Enhanced Type Safety: TanStack Router provides superior TypeScript integration
  • • Better Developer Experience: Improved tooling and debugging capabilities
  • • Modern Data Patterns: Route loaders, typed params, and TanStack Query integration
  • • Flexible Deployment: Not locked into specific platform requirements

Long-term Advantages

  • • Framework Independence: Less vendor lock-in compared to Next.js
  • • Performance: Optimized for modern web performance standards
  • • Future-Proof: Built on stable, well-maintained foundations

⚠️ Risk Mitigation

Potential Challenges

  • • tRPC Context: Current auth context depends on NextRequest and next/headers
  • • Clerk Migration: Must move from @clerk/nextjs to @clerk/tanstack-react-start
  • • Complex Routing: Nested dynamic routes need careful migration
  • • Server Components: Async Next.js page behavior must move to route loaders or query prefetching
  • • Dependency Drift: tRPC v11 release-candidate packages should be upgraded separately from the framework migration

Mitigation Strategies

  • • Parity First: Keep tRPC routers intact before considering Start server-function rewrites
  • • Parallel Development: Keep Next.js version running during migration
  • • Thin Vertical Slice: Prove auth, database, tRPC, and UI with team.grabTeams before migrating every route
  • • Rollback Plan: Maintain ability to revert if critical issues arise
